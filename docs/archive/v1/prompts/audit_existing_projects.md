# Audit Prompt

This prompt is assembled from the shared template and a country overlay.

Use:

```sh
Rscript scripts/render_country_prompt.R --task=audit --country=SE
Rscript scripts/render_country_prompt.R --task=audit --country=FI
Rscript scripts/render_country_prompt.R --task=audit --country=NO
```

Do not audit multiple countries in one run.
