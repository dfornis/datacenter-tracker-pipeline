# Version 1 archive — not active instructions

This directory preserves scripts, prompts, schemas, old standalone scenario output and parallel geometry files from baseline `e3b85cc`. Some historical rules are known to be incorrect. They are retained to explain the change, not to guide new work. The active rules are in the root README, `config/`, `docs/methodology.md` and `prompts/`.

`relocation-manifest.json` records original paths and byte-level checksums. The Norwegian backup is historical input, not a tested rollback mechanism. Use complete immutable release history for restoration. `assets/projects_scenarios.csv` was not generated by the reviewed builder and must not be consumed as current data. The older schema from `docs/old/` is separate from the immediately preceding schema.

The original master and audit CSVs are preserved by the one-time migration in `data/legacy-v1/`. The original world-zone collection is under `data/vendor/legacy-zones/`; active geometry files have separate provenance records.
