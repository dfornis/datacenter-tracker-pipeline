# Discovery Prompt

This prompt is assembled from the shared template and a country overlay.

Use:

```sh
Rscript scripts/render_country_prompt.R --task=discover --country=SE
Rscript scripts/render_country_prompt.R --task=discover --country=FI
Rscript scripts/render_country_prompt.R --task=discover --country=NO
```

Do not discover multiple countries in one run.
